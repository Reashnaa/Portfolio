HDB Resale Price Analysis.

Cleaning a Singapore HDB resale dataset and exploring average monthly resale prices for a chosen flat type and town.

Data period: January 2017–September 202080,156 records after cleaningPython · Pandas

Project overview

As part of my Programming Fundamentals II coursework, I worked with a provided HDB resale transaction dataset. The exercise had two parts: clean the data, then build a Python program to calculate and visualise average monthly resale prices based on a selected flat type and town.

What the exercise involved

  • Check the dataset for duplicate records, invalid values and missing resale prices.
  • Clean the dataset before carrying out the analysis.
  • Allow a flat type and town to be selected, then filter the transactions.
  • Group records by year-month, calculate mean resale prices and display a bar chart.

Data cleaning

80,374Original rows
210Exact duplicate rows
8Additional invalid rows removed
80,156Rows after cleaning

I removed 210 exact duplicate rows, two unusually large floor-area entries (993 and 1,102 sqm), one future lease commencement year (2995), and five missing resale price values. This follows the coursework's specified cleaning approach; in a real transaction dataset, identical rows would need further investigation before deletion.

Example analysis: 2-room flats in Bedok

The chart shows the average resale price for each month with recorded transactions for this selected flat type and town. The filtered data includes 62 transactions across 32 months.

What I found

The highest observed monthly mean was S$245,500 in February 2017, while the lowest was S$180,000 in December 2019. Some months contain only one or two transactions, so these monthly averages can fluctuate and should not be taken as proof of an overall market trend.

Run this analysis yourself

  1. Download both files using the links above and save them in the same folder.
  2. Open the notebook in Jupyter Notebook or VS Code with the Python and Jupyter extensions.
  3. Install the required packages if needed: pip install pandas openpyxl matplotlib ipykernel.
  4. Run the notebook cells from top to bottom. When prompted, enter 2 ROOM for the flat type and BEDOK for the town (use uppercase exactly).
  5. The notebook cleans the dataset, prints monthly averages and displays the bar chart. You can choose another listed flat type and town to explore other combinations.

Dataset: HDB resale transaction extract covering January 2017–September 2020, provided for this Programming Fundamentals II exercise. This is the exact workbook used by the notebook; downloading a newer public HDB dataset may give different results. Note: If your selected combination has no recorded transactions, the original lecturer-format plotting code may raise an error; try another listed combination.
